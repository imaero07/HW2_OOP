Рецепты
Программа которая умеет объединять листы покупок, суммировать необходимые продукты, имеет пометки о диетических рецептах, сохраняет к рецепту ингредиенты

инструкция к открытию
1) git clone <https://github.com/imaero07/HW2_OOP.git>
2) cd HW2_OOP
3) pip install -r requirements.txt
4) pytest

Запуск тестов:
pytest
